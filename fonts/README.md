# Typefaces

Candidate interface typefaces, offered by the switch on the test site. Each file is a Modified Version under the
SIL Open Font License 1.1 (licence texts beside them): cut to weights 400 to 600 (other variation axes fixed: optical
size 14, width 100), subset to the characters isoview prints (Latin-1, Greek, sub- and superscripts, combining
overbars, units and math signs, arrows), and converted to WOFF2 with fontTools. Fonts whose licence reserves their
name are renamed, as the licence requires; their copyright and trademark notices are kept.

|---|---|---|---|

| jetbrains-mono.woff2 | JetBrains Mono (variable), The JetBrains Mono Project Authors | JetBrains Mono | OFL-jetbrainsmono.txt |

| ibm-plex-mono-400.woff2, ibm-plex-mono-500.woff2 | IBM Plex Mono Regular and Medium, IBM Corp. | isoview PXM | OFL-ibmplexmono.txt |
